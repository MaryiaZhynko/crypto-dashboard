

## Description

### Backend 

Backend has been built using NestJS supports microservice architecture. 

## Project setup

```bash
$ pnpm install
```

## Compile and run the project

docker compose up --build

```bash
# development
$ pnpm run start

# watch mode
$ pnpm run start:dev

# production mode
$ pnpm run start:prod
```

docker compose down

## Run tests

```bash
# unit tests
$ pnpm run test

# e2e tests
$ pnpm run test:e2e

# test coverage
$ pnpm run test:cov
```
